## Preserved visual characteristics

- Dark application background with a blue primary action color.
- Outfit heading font and compact sans-serif body typography.
- Left-side navigation on larger screens and a collapsed menu on small screens.
- Rounded controls, restrained borders, and muted dark surfaces.
- Product-first content with playlist artwork and concise action labels.

Authenticated screens will be added when an authenticated deployed session is available. Capturing them must remain read-only unless disposable Spotify test data has explicitly been approved.
